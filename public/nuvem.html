🔒 Política de Privacidade e Proteção de Dados (LGPD)

O Gestão de Torneios Brasil Powerlifting (publicado por Hiroshi Tecnologia) respeita a privacidade dos organizadores, árbitros e atletas em conformidade com a Lei Geral de Proteção de Dados (Lei nº 13.709/2018 - LGPD) e as Políticas da Microsoft Store.

1. Armazenamento 100% Local por Padrão: Todos os dados cadastrados no sistema (incluindo nome, categoria, peso corporal e campos opcionais como CPF, data de nascimento, WhatsApp, redes sociais e condição PCD) são armazenados exclusivamente no banco de dados SQLite local do computador do organizador (%LOCALAPPDATA%\BrasilPowerlifting).

2. Coleta Mínima e Opcional: Nenhum dado sensível é obrigatório para o funcionamento do campeonato. Campos como CPF, data de nascimento e telefone são estritamente opcionais e utilizados apenas pelo organizador local para identificação de atletas entre competições.

3. Sincronização em Nuvem Opcional: O aplicativo não envia dados para servidores externos sem ação explícita do organizador. A sincronização remota só ocorre se o organizador configurar voluntariamente uma URL e Chave/Token de Acesso próprios nesta tela.

4. Exclusão Integral na Desinstalação: O organizador pode excluir atletas ou campeonatos a qualquer momento dentro do aplicativo. Ao desinstalar o software pelo Windows / Microsoft Store, todos os bancos de dados e backups locais são removidos do dispositivo.
