2. Strict Import File Structure

Only the nome (name) and sexo (sex) fields are required. All other fields are optional. Duplicate athletes (who already exist with the same information in this local meet or in the cloud) will be automatically skipped without duplicating records.

Exact Field Name Required? Format / Accepted Values Default if Empty
nome REQUIRED Athlete's full name (max. 120 characters) Stops with error
sexo REQUIRED M or F (also accepts Masculino / Feminino) Stops with error
cpf Optional 11 digits (000.000.000-00 or numbers only) Empty
data_nascimento Optional DD/MM/YYYY, YYYY-MM-DD or just the Year YYYY Empty
whatsapp Optional E.g.: (11) 99999-9999 Empty
cidade / estado / equipe Optional City (text), State UF (e.g.: SP, RJ), Team (text) State: SP | Team: Sem Equipe (No Team)
pcd Optional SIM (Yes), NAO (No), 1, 0, true, false NAO (No)
instagram / youtube / outros_social Optional Athlete's social media (e.g.: @athlete) Empty
modalidade_escolhida Optional E.g.: Full Power, Supino Solo (Bench Only), Terra Solo (Deadlift Only), Push-Pull 1st event of the meet
equipamento_escolhido Optional E.g.: Raw, Classic Raw, Single-Ply 1st equipment of the meet
divisao_escolhida Optional E.g.: Open (for crossover/multiple divisions, separate with ; e.g.: Open;Master 1) 1st division of the meet
categoria_peso_escolhida Optional E.g.: Livre (Open/Unrestricted), 82.5, 90, +140 Livre
